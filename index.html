🐍 Python Cheatsheet

Fun, editable, runnable. Change the code, then press ▶ Run!

🖨️ print — say something

Shows text on the screen.

📦 variables — remember things

A box with a name that holds a value.

⌨️ input — ask a question

A pop-up appears. Type your answer and press OK.

Input is always text. Use int() to turn it into a number you can do maths with.

🔁 loops — do it again and again

Repeat code without typing it lots of times.

🔀 if — make a choice

Do different things depending on the answer.

🎲 random — surprise me!

Pick a random whole number. Great for dice and games. Run it a few times!

Pick a random item from a list.

🧮 maths — count and calculate

Python is a great calculator.

⚖️ comparisons — true or false?

These questions answer True or False. They are what if uses to decide.

You can compare words too. Python checks them letter by letter, like a dictionary.

🔗 boolean expressions — combine questions

Join True/False values with and, or, not.

They are handy inside if.
